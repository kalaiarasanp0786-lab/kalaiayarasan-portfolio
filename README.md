# Kalaiyarasan P — Biotechnology Portfolio

A modern React + TypeScript + Vite portfolio application showcasing the academic background, laboratory skills, research projects, internships, certifications, and achievements of **Kalaiyarasan P** (B.Tech Biotechnology).

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React

## Features

- **Animated Biotech Canvas**: Interactive HTML5 Canvas background rendering DNA double-helix strands, benzene rings, atomic orbitals, and base pairs.
- **Hero Section**: Dynamic typewriter role rotation, portrait ring animation, and quick navigation CTAs.
- **About & Academic Journey**: Research interests, profile highlights, and education timeline.
- **Technical Skills**: Categorized laboratory, research, clinical research, and professional skills.
- **Professional Experience**: Internships at Phycosol Ecotech Pvt. Ltd. and Sun Laboratory.
- **Research Projects**: Expandable project methodologies and highlights for *Computational Multi-Epitope HIV Vaccine Design & Clinical Research Analytics* and *Indoor Algae-Based CO₂ Absorption System Using Chlorella vulgaris*.
- **Certifications & Lightbox Viewer**: Interactive certificate preview modal and credentials showcase.
- **Contact & Resume Download**: Direct contact links and one-click PDF resume download.

## Development

```bash
npm install
npm run dev
```

The development server runs at `http://0.0.0.0:3000`.

## Production Build

```bash
npm run build
npm run preview
```
